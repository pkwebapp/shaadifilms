# **App Name**: Shaadifilms Interactive

## Core Features:

- Home Page Reel: Display a cinematic wedding film reel or image slider with overlay tagline for immediate visual impact.
- Service Galleries: Showcase photo and video galleries for each wedding service category (Pre-Wedding, Hindu, Christian, Destination) with embedded highlight films.
- Transparent Packages: Present tiered service packages (Silver, Gold, Platinum) with detailed inclusions and transparent pricing.
- Online Booking: Enable online booking with calendar availability, package selection, and automated confirmations.
- Client Dashboard: Provide secure client dashboards with options to view/download files, approve photos, and track progress.
- AI-Powered Concierge: Implement an AI chatbot tool to assist users with quick queries about packages and availability.
- Mobile-Optimized UI: Design a smooth, app-like user interface with cards and bottom navigation, optimized for mobile devices.

## Style Guidelines:

- Primary color: Muted gold (#B8860B) for a sense of luxury and elegance.
- Background color: Ivory (#FAF8F0), a desaturated muted gold, provides a sophisticated backdrop.
- Accent color: Deep maroon (#800000), analogous to gold, adds a rich, contrasting highlight.
- Headline font: 'Playfair', a serif font, brings an elegant and fashionable feel to headlines. Note: currently only Google Fonts are supported.
- Body font: 'Poppins', a sans-serif font, complements 'Playfair' with its geometric and contemporary style. Note: currently only Google Fonts are supported.
- Incorporate subtle parallax scrolling, cinematic hover effects, and fade-in animations for a premium user experience.
- Implement a grid-based layout with minimal clutter to ensure easy navigation and visual appeal.
